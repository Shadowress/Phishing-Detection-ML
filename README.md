# Phishing Detection Machine Learning Model

## 📌 Overview
This project is a machine learning workflow developed in Jupyter Notebook for phishing detection. It focuses on training multiple classification models, comparing their performance, and improving the best model through optimization techniques.

---

## 🧠 Models Used
- Random Forest
- Gradient Boosting
- Logistic Regression

---

## 🛠️ Tools & Libraries
- Python
- Jupyter Notebook
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- Joblib

---

## 📓 Notebooks

- `01_model_training.ipynb`  
  Model training and dataset preparation

- `02_model_comparison.ipynb`  
  Model evaluation and performance comparison

- `03_model_optimization.ipynb`  
  Model tuning and optimization process
